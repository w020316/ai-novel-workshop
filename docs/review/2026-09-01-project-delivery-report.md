## 5. 源码审查建议（P3 优化项）

1. **多实例限流失效**：内存限流在横向扩容（多 Vercel/多副本）下各自独立。建议生产接 Redis 或使用第三方网关限流。
2. **敏感配置**：`.env.local` 含智谱与备用 API Key，请确保其被 `.gitignore` 排除且不入库。
3. **`assembler.ts` 顶层 import `useShortTermMemory`**（Zustand hook）被 pure 方法引用，混用了 UI 层与纯逻辑层；建议把短时记忆读取作为依赖参数注入，便于测试与解耦。
4. **`extractKeywords` 的 O(n²) 组装**（2/3/4 字全组合）：项目长文时耗时线性放大，建议限制输入长度或用分词库。
5. **LLM 路由缺少通用请求中间件**：3 个路由的鉴权/限流/请求体校验逻辑重复，可抽公共 helper 收敛。
6. **错误上报缺乏告警**：LLM 调用失败仅 `console.error`，建议接入可观测性（可选）。

## 6. 前端 UI 设计方案（深色主题 + 设计系统）

> 说明：提供可落地的设计规范与代码骨架；完整可交互稿需在设计工具中产出。

### 6.1 色彩系统
- **主色** Primary：`#6C5CE7`（紫蓝），用于主按钮、焦点、选中态
- **强调/成功** Aessence：`#00B894`；**警示** Warning：`#FDCB6E`；**危险**：`#E17055`
- **中性暗色**：`#0F0F14`（背景）、`#1C1C24`（卡片）、`#26262F`（hover）、`#3A3A45`（边框）
- **文字**：`#F4F4F6`（主）、`#A0A0AB`（次）、`#6B6B76`（弱）
- 使用规范：主色占比 ≤10%，用于强导向操作；语义色仅在明确状态场景使用。

### 6.2 排版
- 字体层级：`text-xs(12) / sm(14) / base(16) / lg(20) / xl(28) / 2xl(36)`
- 中文正文行高 1.75，标题 1.2；字重 400/500/700
- 标题用 `font-display`，正文用 `font-sans`

### 6.3 核心组件
- **按钮**：主/次/危险，≥40px 触控高，圆角 8px
- **卡片**：背景 `#1C1C24`，边框 1px，圆角 12px，hover 提升阴影
- **表单**：标签+输入+错误提示三态；聚焦边框主色发光
- **进度/状态徽章**：对应章节状态（见 `ChapterStatusBadge.tsx`）

### 6.4 响应式规则
- 断点：`sm 640 / md 768 / lg 1024 / xl 1280`
- 桌面多栏 → 平板上两栏 → 移动单栏；创作工作台在移动端上下堆叠
- 全部文本/按钮在移动端触控友好，避免横向滚动

### 6.5 落地状态
- 本会话未改写 UI 文件；Scheme 建议连同 `globals.css`、`tailwind.config.ts` 的主题色一并实施（归入「已知限制/后续工作」，见 §7）。

## 7. UX 体验评测与改进建议

> 本会话未启动浏览器做录屏评测（受执行环境限制）。以下为基于代码路径的静态体验评估与结构化建议，完整用户旅程/SUS 需在可运行环境下补测。

### 7.1 核心流程体验盘点
1. **新建项目 → 设定世界观/人物/文风 → 生成章节**：链路完整，均为少数关键步骤，符合 PM 视角预期。
2. **生成中停止**：本次已打通（H1 修复），大幅降低长生成误操作成本。
3. **一致性报告 → 定位章节修正**：报告查看已具备，但「从报告一键跳回章节并定位」仍需手动跳转，可优化。

### 7.2 用户痛点（静态评估）
- **加载反馈**：长章节生成仅有进度条，建议增加当前阶段文案（设定/起草/校验）。
- **错误可恢复性**：生成失败提示较简单，建议给出「重试 / 保留已生成」两个出口。
- **引导**：新用户首次进入缺少分步向导说明渲染核心概念（世界观/伏笔/记忆）。

### 7.3 新功能建议（≥3 项）
| 建议 | 用户价值 | 实现难度 | 优先级 |
|---|---|---|---|
| 1. 章节大纲→进度→世界观的**左导航缩略图/思维导图** | 降低长文全局认知负担 | 中 | 高 |
| 2. **写作助手侧边栏**（实时润色词库、伏笔到期提醒） | 提升创作质量与连贯性 | 中 | 高 |
| 3. **从一致性报告一键定位章节并自动改写** | 缩短「发现问题→修复」路径 | 低 | 中 |
| 4. 自动生成章节标题（复用标题模型） | 减少重复操作 | 低 | 中 |
| 5. **导出前的自动目录与卷分档** | 直接可发布的成品文件 | 低 | 低 |
