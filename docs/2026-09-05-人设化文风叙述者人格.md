## 功能说明

现有去AI味是通用规则；本功能让文风预设绑定**叙述者人格**，正文生成与去AI味润色都按同一人格的腔调输出——至此研究文档 P1 四项（自动开书 / 剧情纲要 / 扫榜拆文 / 人设文风）全部完成。

## 设计要点

1. **纯静态内置库，零 LLM/零网络**：[persona.ts](../src/lib/style/persona.ts) 内置 6 款人格——毒舌编辑、冷峻观察者、烟火气说书人、幽默吐槽手、温柔细腻者、硬朗凌厉者；每款含 画像/叙述习惯/台词习惯/情绪演法/禁忌 五个可执行维度。
2. **三层文风体系互补**：VocabularyProfile（量化指纹）+ StyleGuide（笔法指南）+ NarratorPersona（谁在叙述），互不替代。
3. **题材→人格确定性推荐**：玄幻/末世→硬朗凌厉者、言情→温柔细腻者、悬疑/科幻/历史→冷峻观察者、都市→烟火气说书人、宫斗→毒舌编辑、游戏→幽默吐槽手。
4. **双注入点**：
   - 章节生成：writing.ts 在 StyleGuide 之后注入人格块【叙述者人格（全书统一，必须扮演）】
   - 去AI味：humanize spot 模式把人格约束追加进定点修复 system prompt；full 兜底模式注入 system prompt
5. **向后兼容**：persona 为可选字段，未绑定时所有 prompt 与既有行为完全一致；Dexie schemaless 无需版本升级。
6. **UI（砚斋·墨印不变）**：StyleSelector 项目专属预设卡新增人格 chips（含题材推荐 ★ 标注、一键解绑）；内置预设只读不可绑。
