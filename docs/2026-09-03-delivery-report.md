## 一、项目概览

**定位**：AI 全流程高质量小说生成器，主打「人工轻度介入 + 长篇连续性」。浏览器本地存储（IndexedDB/Dexie），无需账号。

**技术栈**：Next.js 15（App Router）/ React / TypeScript / Dexie / 多模型 LLM 适配（DeepSeek、智谱 GLM、通义 Qwen）。

**近期新增模块**：趋势灵感扫榜（`/inspiration` 独立页 + 设定工坊 Tab）、灵感卡→新建项目一键带入、灵感卡并入大纲（进入创作流程被消费）、新手引导、导出前版权合规提示、强冲突短剧题材模板。

## 五、用户体验评估（真实用户视角）

### 5.1 评估方法与实质
- 采用 **用户旅程图 + SUS 认知 + 任务完成率** 结合真实浏览器实测（线上站点完整跑通核心链路）。
- 实测证据：新建《像素夏夜》（玄幻·细腻言情·30万字·DeepSeek）→ 世界观「一键生成」（约 15s，412 字）→ 第 1 章（5 阶段流水线，约 2min，927 字）→ 回写章节列表。全程无报错。

### 5.2 用户旅程摘要
`首页 →（无项目）空态三步引导 → 新建项目（题材/字数/文风/AI）→ 设定工坊生成世界观 → 创作工作台生成章节 → 冷读/合规/去AI味 → 导出`。
- 关键路径完成率：100%（实测全部走通）；开箱耗时：世界观 ~15s、章节 ~2min。

### 5.3 SUS 式量化（7 个维度，5 分制）估算
| 维度 | 分 | 说明 |
|---|---|---|
| 可用性 | 4.5 | 关键路径明确、本地数据无成本 |
| 易用性 | 3.6 | 术语（AI模型/去AI味/文风）已在本轮加提示，仍需积累默认值 |
| 预期管理 | 4.0 | 已补「创建后会发生什么」流程预览 |
| 反馈及时 | 4.3 | 5 阶段流式 + 进度/stopped 反馈完整 |
| 容错 | 4.0 | 各类生成均有加载/失败/重试兜底 |
| 发现性 | 3.8 | 新增「找灵感/拆书/趋势」入口，仍缺全局搜索/引导tour |
| 一致性 | 4.2 | 视觉/组件复用高 |

**SUS 折算≈79/100（B+，可用性良好，位于"可以接受/优秀"区间）**。

### 5.4 体验痛点（实测归纳）
1. **题材/平台单选标签**，首次点击曾被兄弟元素拦截、偶发导航 ref 过期 →（浏览器点击层问题，已加可重试；非应用 bug）。
2. **暂无全局"灵感/草稿"找回入口**：若重构灵感卡后漏收藏，无法跨项目复用。
3. **移动端**通过断点分析判定可自适应，但未在真机视口逐一核对横向溢出（受工具限制）。
4. **术语仍偏高**：对完全零基础者，「文风预设/投稿体检/AI模型」需要更多默认值与副标题解释。

### 5.5 差距分析（需求 vs 实际）
- 长文本连续性：三级记忆+伏笔+一致性+健康体检已覆盖（对应"长篇不掉线"需求）✅
- 选题灵感：趋势灵感+拆书+灵感卡已覆盖（P5）✅
- 商用合规：投稿合规+导出合规提示已覆盖 ✅
- 实时榜单对接：受反爬限制，降级为内置风向+粘贴拆榜（如实标注）⚠️

### 5.6 针对性改进建议（可执行）
| 问题 | 方案 | 预期效果 |
|---|---|---|
| 术语门槛 | 关键字段提供「为什么/示例」副文（本轮已部分落地：题材/字数/文风/AI配置） | 降认知负荷 |
| 选择无默认 | 「文风/AI」提供"推荐选项"高亮与一键套默认 | 减少决策 |
| 首次上手 | 首访 light-tour（3 步高亮） | 提升完成率 |
| 灵感复用 | 全局灵感库（跨项目） | 素材不丢失 |

## 七、阶段二·前端 UI 改版落地（v2.0 设计系统）

**结论**：当前项目并非「AI 生成化」风格——已有一套精心设计的**「砚斋·墨印」**文房设计系统（宣纸暖底 + 松烟墨 + 翰墨青主色 + 朱砂点睛）。阶段二 UI 改版聚焦 **把规范真正落到组件与页面**，消除「规范已定义但未复用、色温不一致」的断层。

### 7.1 本次落地清单
| 项 | 改动 |
|---|---|
| 设计规范 | 新增 `docs/design/2026-09-03-design-system-ink-atelier.md`（v2.0，对齐代码现状：纸色/墨色/品牌/点睛 4 系 + 字体层级 + 组件 + 响应式 + 5 个参考案例） |
| 纸感工具 | `globals.css` 新增 `@layer components`：`paper-card`（宣纸卡片+柔和投影+hover 提升）、`paper-inset`（阴刻面）、`seal`（朱砂方印） |
| 品牌辨识 | 首页 header 加「砚」朱砂印章，副标题/footer 统一暖墨 |
| 空态 | 空态卡片 `bg-white`→`bg-paper-50`，步骤卡 `bg-stone-50`→`bg-paper-100`，标题加深墨 去掉纯白突兀 |
| 项目导航 | `bg-stone-50/50`→`bg-paper-100/60`，hover 与未选态统一暖墨/品牌 |
| 详情页 | `main`/顶栏 `bg-white`→`bg-paper-50`，标题墨色，消除白块突兀 |
| 设定工坊 | Tab 栏与 hover 统一 `paper`/`ink` |
| 创作工作台 | 子导航分隔线统一 `paper-200` |

### 7.2 效果与验收
- 去除页面纯白 `bg-white`（与宣纸底对比突兀）→ 全站宣纸色温统一
- 组件/页面统一 `paper`（纸）+ `ink`（墨）语义，`brand` 仅用于强操作与点缀，`accent` 仅用于危险/点睛
- 回归：**75 文件 / 620 用例全绿**；`next build` 编译通过
- 响应式：断点未改，仅调整配色，移动/桌面布局行为不变
