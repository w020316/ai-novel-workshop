## 一、背景

应用户要求，系统吸收三位网文方法论创作者的视频内容并落地到项目。分三批完成：

1. 人设方法论（我不是码神·人设篇）→ 人设生成器重写
2. 三视频专题（脑洞四分类 / 文笔三板斧 / 专属数据库）→ 灵感、世界观、正文、技能库
3. 「我不是码神」全量作品吸收 → 扫榜拆书原则、开书包点击域、4 个新技能
4. 情绪方法论（甲鱼不是龟）+ 三线并行（啊云云）→ 技能库 2 个新技能 + 剧情设计第四原则

## 二、改动清单

### 2.1 人设生成器（`src/lib/llm/generators/character.ts`，eab8cb7）
- 内核冲突句式：「渴望X却害怕Y所以总是Z」
- 辨识标签 + speechStyle 附示范台词 + appearance 只写具体特征
- behaviorPattern 绑定剧情功能位；人物名清洗 `sanitizeCharacterName`
- 记忆注入同步：`memoryToPrompt` 注入 speechStyle/catchphrase/behaviorPattern

### 2.2 正文生成法则（`src/lib/agents/writing.ts`，bd09b25 / ec4b9c0）
- 三大黄金法则：展示而非讲述 / 冲突驱动 / 悬念承上启下（断章）
- 人设落地法则：对话立人设 / 行为显内核 / 插曲塑人设
- 文笔三板斧（网文资料菌）：抽象变动作 / 环境碰人物 / 过场快对线慢

### 2.3 技能库新增 7 个内置技能（`src/lib/skills/store.ts`，默认关闭）
| 技能 | 来源 | 注入环节 |
|---|---|---|
| 单章五件套·拆书自查 | 我不是码神第3集 | plot/write |
| 高级对白四件套 | 网文资料菌144 | dialogue |
| 群像四件套 | 网文资料菌142 | style |
| 期待感三层引擎 | 猫神写作51 | plot |
| 顶级反派四维度 | 猫神写作52 | plot |
| 神级反转四招 | 猫神写作53 | plot |
| 逻辑三账自检 | 网文资料菌143 | review |

### 2.4 灵感与世界观的脑洞内核（bd09b25）
- `inspiration/starts.ts` 换一批：AI 生成书名须暗含脑洞内核（金手指/剧情/设定/角色类）
- `llm/generators/worldview.ts`：世界观生成必须带「让人眼前一亮」的设定创意

### 2.5 开书包点击域（`llm/generators/book-package.ts`，ec4b9c0 / 67f6201）
- 书名简介优先级高于正文（点击域）；书名放大噱头
- 简介三句话结构 + 三式写法（反差式/标签堆砌式/情感认同式）+ 与书名卖点高度匹配

### 2.6 扫榜拆书三原则（`lib/rank/viral.ts`，67f6201）
- 拆骨不拆皮（拆剧情骨架为何吸引人，禁止复述剧情）
- 优点提炼公式化（可套用句式/结构）
- 借鉴不抄袭

### 2.7 第四批：情绪方法论 + 三线并行（本次提交）
- 技能库新增 2 个内置技能（默认关闭，plot 环节注入）：
  - **情绪压制与前置期待**（甲鱼不是龟《网文挣钱的底层逻辑》）：开头=主线第一引爆点，读者追的是「压制解除后能兑现的情绪结果」；冲突爆发前铺垫主角破局底牌（前置期待）；敌友群三方情绪塑造（敌方压恨意 / 友方撑底气 / 群众见证反差）；爽点=情绪结果的兑现；目标三层透明（现状—中期目标—最终目标）
  - **三线并行·剧情跌宕**（啊云云《如何让剧情跌宕起伏》）：主线 50-60% / 支线 30-40% / 暗线 10-20%；六大并行技巧（节奏交错 / 伏笔分层埋 / 信息差控制 / 角色联动 / 三线合流 / 收束管理）；新手五避坑（无支线 / 支线夺主 / 暗线突现 / 三线齐高潮 / 伏笔不回收）
- 剧情设计 Agent（`src/lib/agents/plot-design.ts`）新增第四原则【情绪工程】：前置期待 + 三方情绪，压得越狠、兑得越爽（与黄金三章开篇法则互补，不重复）
- 内置技能增量补齐机制天然生效：`ensureSeedSkills` 按 `builtin-skill-N` 确定性 id 只补缺失项，不影响既有启停状态
