## 一、背景

应用户确认，本轮同时迭代三个方向，从小到大依次交付：

1. **C 期待感卷级规划**：把「期待感三层引擎」（技能库已有技能）落到卷规划层
2. **B 黄金三章生成器**：前 3 章开篇专项强化（切入点/代入感/钩子密度）
3. **A 拆书工坊闭环**：剧情骨架（五件套+因果链+可复用公式）拆解 → 存为灵感卡/技能

## 二、改动清单

### 2.1 C 期待感卷级规划（61932a1）

- 新增 `src/lib/outline/anticipation.ts`：纯函数卷级期待感设计
  - **宏观**：第 1 卷埋「终极天坑」+ 抛出第一块碎片；中间各卷给递增编号碎片（新线索+翻转旧碎片）；末卷揭晓全貌
  - **中观**：每卷一个具象化「阶段性大奖」（立身之战 → 新阶层门票 → 黑手交锋资格 → 终极对决）+ 一条「压抑→释放」节奏
  - **微观**（章内将爆即断/信息不对称）由写作法则与技能库在章级注入，不在卷级展开
- `src/lib/outline/volume-plan.ts`：`planVolumes` 每卷摘要自动拼接 `期待感设计：大奖/节奏/天坑线索`
- 流转路径：卷摘要 → 记忆层 `memoryToPrompt`「本卷剧情走向」→ 正文生成自动读到
- 模板路径（`template.ts`）与大纲视图 UI 无需改动，自动生效

### 2.2 B 黄金三章开篇强化（8215b83）

- 新增 `src/lib/agents/golden-three.ts`：`goldenThreePrompt(chapterNo)` 纯函数
  - **第 1 章**：切入点（第一段进冲突现场，前三段完成「主角亮相+危机+悬念」）/ 代入感（要什么怕什么凭什么）/ 钩子密度（每 500 字一个钩）
  - **第 2 章**：先给再压（兑现首章钩子一部分后压更大危机）/ 金手指首次实战亮相
  - **第 3 章**：第一个小高潮（打脸/翻盘/立誓，完成追读确认）/ 期待升级
  - 每章均要求：开篇结构可借鉴同题材高成绩作品，严禁照抄情节语句
- `src/lib/agents/writing.ts`：`buildWritingPrompt` 在 chapterNo ≤ 3 时注入该块（其余章号零影响）

### 2.3 A 拆书工坊闭环（885d792）

原有能力：确定性指标（对话占比/节奏/爽点密度/钩子断章）+ LLM 建议 + 灵感卡。本次补齐「拆书→沉淀→复用」闭环：

- `src/types/index.ts`：`Deconstruction` 新增可选字段 `skeleton`（五件套）/`causalChain`/`formula`（旧记录兼容）
- `src/lib/deconstruct/analyzer.ts`：
  - LLM 拆解协议扩展：剧情骨架五件套（核心目标/开篇钩子/核心冲突/爽点情绪点/章末悬念，对齐技能库「单章五件套」）+ 因果链（3-6 步逐步升级）+ 可复用公式（抽象到角色位，拆骨不拆皮）
  - 防御：五件套五项齐全才采用、因果链不足 3 步丢弃，防半残骨架误导复用
  - 新增 `deconstructionToSkill(dec)`：拆解结果 → plot 类自定义技能入参（纯函数）
- 拆书工坊页面（`settings/deconstruct`）：
  - 新增「剧情骨架」五件套网格 + 「因果链」有序列表 + 「可复用公式」高亮块展示
  - 新增「存为技能」按钮：一键沉淀为技能库自定义技能（技能库启用后于情节编排环节自动注入）
- 新增 E2E `e2e/deconstruct-workshop.spec.ts`：粘贴文本 → Mock LLM → 校验骨架/因果链/公式/灵感卡展示 → 收藏灵感卡 → 存为技能（chromium + mobile-chromium 双端）

### 2.4 三线并行卷级落地（ba3db3f / 本次提交）

把内置技能「三线并行·剧情跌宕」（啊云云）从技能层下沉到卷规划层，与「期待感三层引擎」同模式：

- 新增 `src/lib/outline/three-lines.ts`：纯函数卷级三线设计
  - **主线（50-60%）**：首卷完成第一引爆点并写清「现状—中期目标—最终目标」；中间卷向大奖推进、压抑释放交替；倒数第二卷真相/巨大危机拉满；末卷终局清算回应开局
  - **支线（30-40%）**：首卷开设配角支线（记忆钩子+私人目标）；中间卷节奏交错推进；倒数第二卷反哺主线（救场/背叛/证据）；末卷全部收束不留断线
  - **暗线（10-20%）**：首卷埋种子（与终极天坑呼应）；中间卷递增碎片；倒数第二卷浮出水面与主线交汇；末卷三线合流引爆、回收全部伏笔
- `src/lib/outline/volume-plan.ts`：`planVolumes` 每卷摘要自动拼接「三线安排：主线…支线…暗线…」
- 流转路径：卷摘要 → 记忆层「本卷剧情走向」→ 剧情设计/正文生成自动读到；与 plot-design 第四原则【情绪工程】（前置期待+三方情绪）形成「卷级结构 + 章级情绪」双层落地

### 2.5 投稿格式排版导出（本次提交，UX 评估 N4）

- 新增 `src/lib/export/submission.ts`：确定性投稿排版引擎
  - 书名/简介开头，无 Markdown 目录/分隔线/元数据块等平台不需要的标记
  - 依据大纲卷规划自动插入「第N卷 卷名」分隔（每卷一次）
  - 章节标题「第N章 标题」；段落首行全角空格缩进（默认 2 格，可调），段间空行
  - 自动清理 Markdown 痕迹（标题/列表/加粗标记）
- 导出中心（`project/[id]/export`）新增「投稿格式 TXT」卡片，可直接粘贴到作家后台
- 新增 6 例单测 `submission.test.ts`
