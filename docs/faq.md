# FAQ · 常见问题

> 更新：2026-09-06

## 模型与 Key

**Q：API Key 存在哪里？安全吗？**
A：Key 只存浏览器本地（localStorage/IndexedDB），请求经服务端代理转发但不落库。也可用环境变量（`DEEPSEEK_API_KEY`/`GEMINI_API_KEY` 等）配置服务端默认 Key。

**Q：可以完全免费使用吗？**
A：可以。模型配置页支持免费模型发现；也可用 Ollama 接入本地模型（零成本、离线），见 `docs/2026-09-05-本地离线模型端点Ollama.md`。

**Q：生成报错「模型返回内容为空」？**
A：多为免费模型限流或截断，可在模型配置切换供应商；编排器内置指数退避重试与降级链，持续失败时换模型再试。

## 创作流程

**Q：生成的正文偏离主线怎么办？**
A：系统已强制注入「主线锚点」（大纲主线程+高潮节点+当前卷核心冲突）。若仍漂移：先在设定工坊锁定大纲与世界观（locked），再重新生成；单段问题用「重写指定段落」。

**Q：人物对话腔调雷同、像同一个人？**
A：人设生成已包含「说话风格+示范台词+口头禅」，记忆装配会注入这些字段。可在人物档案中补写示范台词，并在技能库启用「高级对白四件套」。

**Q：什么是抽卡模式？**
A：生成一次同时产出多个候选正文供挑选（编排器 `candidateCount`），适合开篇章、关键章择优。

**Q：长篇写到几十万字后 AI「失忆」？**
A：三级记忆体系自动装配前情：近期章节原文入短期记忆，更早章节摘要按相关性检索入中期，设定/大纲/伏笔常驻长期；Token 超预算会自动分层压缩。配套一致性校验与剧情纲要（ArcCanon）防设定漂移。

**Q：技能库是什么？怎么自建？**
A：内置 15 个网文方法论技能（人设/期待感/反派/反转/对白/群像/逻辑等），默认关闭，启用后按生成环节自动注入。可导出 JSON 编辑后导入，建立自己的「专属数据库」。

## 数据与部署

**Q：数据存在哪？换电脑怎么办？**
A：全部数据在浏览器 IndexedDB。导出中心支持 JSON 全量备份/恢复、打包导出；也可用 WebDAV 同步跨设备。

**Q：支持导出什么格式？**
A：TXT / Markdown / EPUB（含目录）/ JSON 备份，另有一键打包导出。

**Q：本地开发/部署？**
A：`npm install && npm run dev`；生产 `npm run build`。已配置 Vercel 持续部署（push master 自动发布）。

**Q：手机上能用吗？**
A：支持移动端（抽屉导航、响应式布局，含移动端 E2E 用例）。
