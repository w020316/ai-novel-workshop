# 砚斋·墨印 设计系统规范（Design System · v3）

> 适用：AI 小说制作工坊
> 定位：**文房墨印**美学 —— 宣纸的温、松烟的墨、朱砂印的艳。目标是把写作工具做成「一方可沉下心写作的砚台」，而非冷冰冰的通用 SaaS 面板。
> 对应落地：首页 Hero（本设计系统 v3 的首次高保真实现），全局 `globals.css` 设计令牌。

---

## 1. 概念与差异化

一句话记忆点：**「纸」上是松烟墨的字，「朱砂印」盖在关键动作上。**

- 不谈 AI 的科技感，而谈「纸、墨、印」的文房温度 —— 与小说创作的心流天然契合。
- 反模板化：拒绝紫渐变白底、拒绝通用无衬线；全站以 **衬线大标题 + 暖纸底 + 墨绿主色 + 朱砂点睛** 构成辨识度。
- 动效克制而有仪仗感：首屏分层「浮现」（ink-rise），如落笔成章，不喧哗。

## 2. 色彩系统

### 2.1 令牌（CSS Variables，见 `globals.css`）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--background` | `#f5f0e6` | 宣纸暖底（页面底色） |
| `--background-deep` | `#ece2ce` | 纸色加深（分区/内嵌面） |
| `--foreground` | `#29231b` | 松烟墨（正文/前景） |
| `--ink-soft` | `#5d554a` | 次级墨色（辅助文字） |
| `--ink-faint` | `#8c8374` | 弱墨色（提示/元信息） |
| `--line` | `#e4dbc8` | 分栏线/描边（宣纸灰） |
| `--brand`（翰墨青） | `#2a6658` | 主色：链接、强调、焦点、操作主调 |
| `--accent`（朱砂印） | `#c0332c` | 点睛色：印章、主 CTA、删除/风险 |

### 2.2 色板（Tailwind `theme.extend.colors`）

- **brand**（翰墨青 50–950）：`#2a6658` 为主题中点，用于品牌、链接、选中态、焦点环。
- **accent**（朱砂印 50–900）：`#c0332c` 为主题中点，仅用于「点睛」——主 CTA、印章、少量高强调。
- **paper**（宣纸暖灰 50–900）：页面/卡片底，白中带暖。
- **ink**（松烟墨 300–900）：文字层级。
- **stone**（暖墨中性）：覆盖默认 Tailwind stone，保证全站色温统一。

### 2.3 使用规范

- **主色/辅助色比例**：brand（墨绿）约 60%、paper/ink（中性）约 35%、accent（朱砂）约 5%。朱砂只做点睛，避免大面积红。
- **不可用**：纯黑 `#000`、纯白 `#fff`、默认灰 `#6b7280` —— 一律换用本系统的墨/纸/stone 令牌，保证色温统一。
- 分隔线用 `--line`，不用 `border-gray-200`。

## 3. 排版规范

- 无衬线正文：`Noto Sans SC / 思源黑体 / 微软雅黑`（`--font-sans`）
- 衬线标题与文学正文：`Noto Serif SC / Source Han Serif SC / 宋体`（`--font-serif`）
- 标题一律衬线、字重 700、字距 `0.02em`；正文行高 1.8–2.0（`font-novel` 用于小说正文，行高 2、字距 `0.035em`）。

| 层级 | 字号 | 字重 | 用于 |
|---|---|---|---|
| Display | 48–60px | 700 serif | 首页 Hero 大标题 |
| H1 | 30px | 700 serif | 页面主标题 |
| H2 | 24px | 700 serif | 区块标题 |
| H3 | 18px | 700 serif | 卡片标题 |
| Body | 14–16px | 400 | 正文说明 |
| Caption | 12px | 400 | 元信息/提示 |

## 4. 组件规范

- **按钮**：主 CTA = accent 朱砂底、宣纸色文字、圆角 `0.5rem`；次级 = outline 墨绿边；禁用 = `stone-300`。图标用 lucide，默认尺寸 16–20px。
- **表单**：输入框 `border` = `--line`，聚焦 `focus:border-brand-500` + 墨绿泛光焦点环；label 用小字 `text-ink-soft`。
- **卡片**：`.paper-card` —— `#fdfaf3` 底 + `--line` 细线 + 柔和投影，hover 抬升。首页项目卡沿用。
- **印章**：`.seal` 朱砂小方印（品牌/操作点睛），`.seal-accent` 朱砂文字。
- **分区**：`.paper-inset` 纸色加深内嵌面（导航/代码块等）。

## 5. 布局与响应式

- 全局 `overflow-x:hidden` + `max-w-6xl` 居中主容器。
- 网格：`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`（项目卡），窄屏单列、平板双列、桌面三列。
- Hero 氛围层（墨晕圆、竖排水印印章）在 `md` 以下隐藏水印，避免挤压；模糊装饰均由 `overflow-hidden` 裁剪，杜绝横向滚动。
- 移动端导航收窄（标题缩短、仅保留关键链接）。

## 6. 动效

- 首屏「浮现」：`.reveal`（ink-rise，0.7s 从 +16px 浮起渐显），Hero 层级 `0ms/90/180/270/360ms` 依次浮现；项目卡按索引 `i*80+120ms` 级联。
- `prefers-reduced-motion: reduce` 全局关闭动画/过度（已内建）。

## 7. 设计参考（方向性调研）

以下为「文房/阅读/写作工具」类优质 UI 的**提取方向**（不构成直接素材引用）：

| 参考方向 | 代表来源 | 提取点 |
|---|---|---|
| 阅读排版沉稳感 | 豆瓣阅读 / 起点 / 掌阅 排版 | 衬线正文、行高、窄栏阅读宽度 |
| 暖纸 / 纸质质感 | 站酷「文房/手账」类作品、Notion 暖色模板 | 纸色层次、柔和投影、细描边 |
| 印章 / 盖章点缀 | Dribbble 中华风品牌视觉 | 朱砂小印、竖排水印、留白 |
| 心流写作工具 | 开源 `zelay`/`MarkText`、沉浸写作 UI | 减少视觉噪音、聚焦内容、克制动效 |
| 书籍/封面构成 | Behance 书籍装帧设计 | 大留白、衬线对比、强烈文字层级 |

**落地证据**：本文档规范已在本轮首页 Hero 改造中实现（见 `src/app/page.tsx` + `src/app/globals.css`），可作为后续各页统一的样式基准。
