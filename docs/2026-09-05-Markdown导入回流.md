## 一、功能概述

导出中心新增 **「Markdown 导入回流」**：把导出的 Markdown 文件（或自行整理的 `## 第N章 章名` 格式文档）导回当前项目。正文可在外部编辑器 / Git 仓库中修改后回流，实现「文档可 git、可外部编辑」的双向工作区。

## 二、实现要点

| 项 | 说明 |
| --- | --- |
| 解析 | `parseMarkdownDoc` 纯函数：与 `exportMarkdown` 输出互通（往返测试覆盖）；提取 `# 书名` / `> 简介` / `- **题材**：x` 元数据 |
| 章节标题 | `##`~`####` 级均可；兼容 `第N章：标题` 变体；章号支持中文数字（一/十二/两百/一万零一） |
| 回流三分支 | 新章号 → 新建（卷号按大纲卷区间反查）；章号存在且标题/正文变化 → 更新；无变化 → 跳过 |
| 版本保护 | 更新正文前旧版自动快照进 `chapterVersions`（与章节页手动保存行为一致），人工内容不丢失 |
| id 复用 | 更新分支复用原章节 id（`projectId + chapterNo` 定位），不产生重复章号记录 |
| UI | 导出中心「从备份恢复」旁新增回流卡片，导入后刷新统计并 toast「新建 X 章，更新 Y 章，无变化 Z 章」 |

## 三、设计取舍

1. **回流目标为当前项目**（页面上下文已知 projectId），不新建项目；备份恢复负责整项目迁移，二者职责分明。
2. **空正文章节跳过**：目录区残留的章标题行（无正文）不落库。
3. **元数据只解析不落库**：项目标题/题材以项目内数据为准，避免外部文件覆盖项目设定。
