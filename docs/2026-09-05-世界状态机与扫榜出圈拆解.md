# 交付文档：世界状态机 + 扫榜拆解出圈逻辑

> 日期：2026-09-05
> 来源：参考两个抖音视频中的开源写作工具功能（笔枢「跨章世界状态聚合」、Openwrite 1.3「扫榜拆书出圈逻辑」），结合本项目「砚斋·墨印」体系落地。

## 一、功能清单

### A. 世界状态机（记忆管理页新卡片）
- 新增 `src/lib/worldstate/machine.ts`：纯函数聚合器（确定性、无 LLM/无网络，与全书避撞体检同模式），从 情节线/伏笔/章节摘要/大纲 注入数据聚合出一张「世界状态快照」：
  - **时间线进度**：已写章数、最新章/卷、累计字数、按大纲计划完结章号计算的进度百分比
  - **章号空洞**：识别删除留下的洞（防止断更空窗）
  - **情节线状态**：每条线的首次/最近推进章号；active 主线/支线超过 `THREAD_STAGNANT_GAP=15` 章未推进即标记「停滞」（主线锚定防线）
  - **伏笔埋/收进度**：已埋/待收/已收/弃置计数 + 已到/过计划回收章仍未收的「逾期伏笔」清单
  - **人物在场统计**：按章节摘要聚合出场章数、最近出场章与末次人物状态（前 12 人）
  - **风险提示**：空洞 / 逾期伏笔 / 主线停滞 / 支线停滞四类确定性规则
- 新增 `src/components/memory/WorldStateCard.tsx`：记忆页一键「生成世界状态快照」，风险琥珀色警示、无风险绿色确认，完全沿用现有卡片视觉体系。
- 单测 `src/lib/worldstate/machine.test.ts`：10 用例（零值/进度/空洞/停滞阈值边界/逾期排序/在场截断/确定性）。

### B. 扫榜拆解出圈逻辑（趋势页新入口）
- 新增 `src/lib/rank/viral.ts`：
  - `heuristicViralBreakdown`：确定性启发式拆解（书名关键词 → 题材定位/金手指/钩子/情绪爽点/可借鉴手法 + 榜单位次钩子提示）
  - `generateViralBreakdowns`：LLM 优先拆解榜单头部作品（默认前 5 部，控制 token），失败或产出半残逐部降级启发式，绝不阻塞
  - `viralBreakdownsToCards`：拆解结果转为 `structure` 灵感卡（五要素齐全），一键存入灵感库跨项目复用
- 趋势页实时榜单结果区新增「拆解头部作品出圈逻辑」按钮与拆解结果展示（标注 AI 拆解 / 启发式拆解）；重新抓取榜单自动清空旧拆解结果。
- 单测 `src/lib/rank/viral.test.ts`：10 用例（题材推断/兜底/爽点命中/LLM 匹配/降级/半残回退/maxN 截断/空列表/落卡内容）。

## 三、设计取舍
- 世界状态机为纯函数而非 LLM：跨章状态聚合必须确定性可测、零成本、可重复刷新，风险规则明确可解释。
- 出圈拆解 LLM 失败逐部降级启发式而非整体失败：扫榜场景下「有结果永远好于没结果」，且每张卡标注来源（AI/启发式）供用户判断可信度。
- 拆解对象限定榜单头部（前 5 部）：头部位次才具出圈参考价值，同时控制 LLM token 成本。
