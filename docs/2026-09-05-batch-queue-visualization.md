## 一、功能：批量续写队列可视化

**背景**：批量续写（至 50 章）原有单一进度条 + 「第 X/N 章·阶段」文字，长篇挂机时看不到逐章推进，用户无法判断当前写到哪里。

**实现**：
- [batch.ts](../src/lib/agents/batch.ts) 新增纯函数 `computeBatchQueue(startChapterNo, count, runningIndex, stage)`：由进行中章序号推导整批逐章状态（pending / running / done + 当前章阶段），dagger 确定性可测，复用既有 `onProgress` 快照，无新增持久化/IO 开销。
- [workbench/page.tsx](../src/app/project/[id]/workbench/page.tsx)：进度条上方新增**逐章格子网格**——灰=待生成 / 蓝（呼吸动画）=进行中+阶段 / 绿✓=已完成；悬停显示章号与阶段明细（记忆装配/剧情设计/文笔创作/一致性校验…）。

**用户价值**：长篇批量时一眼可知当前推进到第几章、本章处于哪一步、已完成哪些；配合「暂停/继续」缩短对挂机进程的掌控感。

**测试**：新增 4 条 `computeBatchQueue` 单测（未开始/进行中/末章临近完成/非.begin 章号对齐）。
