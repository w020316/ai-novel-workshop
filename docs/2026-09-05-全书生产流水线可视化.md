# 全书生产流水线可视化（P3）交付说明

> 日期：2026-09-05 　commit：58f0d31（Vercel success）　对标：ai-story-builder 节点图 pipeline

## 一、功能定位
在工作台新增「全书生产流水线」面板：按大纲卷分组、逐章一个节点格，一眼看清整本生产进度；失败章红格直接定位跳转，规划占位章虚线展示。**纯前端确定性实现，零 LLM / 网络依赖**，结果确定可测。

## 二、实现内容

### 1. 纯函数 `buildPipeline`（src/lib/workbench/pipeline.ts）
- 输入：`chapters`（全部章节记录）、`volumes`（大纲卷规划）、`batchJob`（最近批量任务现场）
- 分组规则：
  - 章节记录按自身 `volumeNo` 分卷，卷标题取大纲同名卷，无则回退「第 N 卷」
  - 大纲各卷 `chapterRange` 内尚无记录的章号 → `planned` 占位节点
  - `volumeNo` 超出大纲范围的章照常成组，不丢弃
- 节点状态（优先级从高到低）：`failed`（批量失败章号，即使重试耗尽未落库也红格）→ `completed`（`needsRecheck` → `recheck` / 否则 `done`）→ `pending` → 中间态 `active`；无记录 → `planned`
- 非法卷区间（end < start）安全跳过；统计聚合 done/recheck/active/pending/failed/planned

### 2. 组件 `PipelineBoard`（src/components/workbench/PipelineBoard.tsx）
- 按卷分组的节点网格 + 总进度条（done/total + 百分比）+ 彩色图例
- 每格 hover 提示：章号 · 状态 · 标题字数（失败格显示失败原因）
- 点击任意格子（含 planned 占位）跳转 `/project/<id>/workbench/chapter/<n>`
- 颜色沿用「砚斋·墨印」体系：done=brand 绿、recheck=amber、active=brand 浅+脉动、failed=red、planned=虚线灰
- 无章节且无规划时整卡自动隐藏

### 3. 工作台页接入（src/app/project/[id]/workbench/page.tsx）
- `load()` 同步读取 `getOutline`，面板置于「全书避撞体检」与「章节列表」之间
- 失败章与既有断点续写横幅联动：红格定位 → 「继续批量续写」从该章重试

## 四、P3 取舍说明
- **DAG 边省略**：章节为线性依赖（后章依赖前章记忆回溯），网格天然表达序关系，无分支并行语义，引入 DAG 边属过度工程
- **任务队列后台常驻不做**：项目为纯前端 + IndexedDB 本地优先架构（Vercel 无常驻进程），批量续写已有章级状态持久化 + 断点续跑 + 心跳互斥锁 + 自动重试，后台常驻 worker 收益不成立，维持现状
