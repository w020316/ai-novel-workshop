## 一、功能：一致性自愈（定位 → 聚合 → 建议 → 标记处理）

**背景**：一致性校验页此前只展示「哪章报错」，作者仍要在各章报告间手动翻找设定类问题（人设矛盾/世界观冲突），无法快速形成修订方案。

**实现**：
| 层 | 内容 |
| --- | --- |
| 纯函数库 | [consistency-heal.ts](../src/lib/agents/consistency-heal.ts)：`aggregateConsistencyIssues` 把各章 **character/worldview** 问题按「类型+描述」指纹跨章折叠，统计命中章数/次数/最大严重度，`plot/伏笔/文风` 归为正文侧；`buildCharacterFixProposal` 生成可复制的人物修订建议；`topCriticalIssues` 筛 error 级优先项 |
| UI | 一致性校验页顶部新增**「设定自愈 · 跨章聚合」**卡片：error 徽标 / 命中章数·次数 / 建议文本 / 「复制建议」+「标记已处理」（localStorage 记指纹，不侵入 db schema）；「显示已处理」可展开 |
| 安全边界 | 只**定位+建议**，不自动改写设定——避免未经审阅覆盖人设/世界观 |

**用户价值**：先修人设与世界观这类「牵一发动全身」的设定侧问题（改一处救多章），剧情/伏笔类正文问题另循章修改；「标记已处理」让反复出现的同类问题不再重复打扰。

**测试**：7 条单测（空报告/跨章折叠/世界观归类/error 优先排序/建议文本/内容侧计数/指纹去空白）。
