## 一、功能：一键打包全部格式

**背景**：导出中心此前需分别点击 TXT / Markdown / EPUB / 备份 四张卡片逐个下载，交付一份作品要给多个平台投稿时来回操作。

**实现**：
- [export-pack.ts](../src/lib/export/export-pack.ts) 打包库：
  - `compileExportPackManifest` 纯函数——TXT/Markdown 文本条目与 EPUB/备份 Blob 条目分离（便于单测）
  - `buildExportPackZip` 复用 jszip（epub 同款）动态导入生成 zip，DEFLATE 压缩
  - `safeEntryName` 防 zip 路径穿越（拒绝 .. / 分隔符 / 空串 / NUL）
- 导出中心新增第 5 张卡片「**一键打包全部格式**」：一键产出 **TXT + Markdown + EPUB + 避撞体检附录**（TXT/MD 已含附录章）为单个《项目名_全格式.zip》；文件名清洗非法字符；disabled 沿用完成章>0；失败降级提示。

**用户价值**：多平台投稿 / 存稿归档从「点 4 次下载」降到「1 次打包」，交付链路一步到位。

**测试**：5 条单测（txt+md 条目 / 可选 blob 并入 / 空 blob / safeEntryName 放行与拒绝）。
